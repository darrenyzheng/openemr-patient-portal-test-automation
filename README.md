# Test-Automation-Patient-Portal-
test automation

## Features

- **Page Object Model (POM)** Page Object Model (POM) to organize browser interactions into dedicated page classes
- **Authentication tests** Login and authentication testing covering valid and invalid credentials, required field validation, email format checks, password visibility, and logout behavior
- **Profile tests** verifying edit modal behavior, cancel and close controls, and modal dismissal after page refresh
- **Appointment tests** covering page refresh behavior, appointment form controls, cancellation, and validation alerts when saving without a selected time
- **Messaging tests** Messaging tests covering message composition, sending, compose window controls, message count updates, and archiving sent messages
